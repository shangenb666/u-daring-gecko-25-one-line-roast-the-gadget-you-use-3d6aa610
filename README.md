My phone monitors my sleep, counts my steps and follows me everywhere I go — then dies at 4 p.m. like it's the one who had a long day.

The program writes that line to `entry.txt` in the output directory.
One original line, at most 200 characters, judged head to head on which
roast is the funniest, the freshest and the neatest.

## Run it

```sh
python3 -P -s main.py
```
